# Grand Theft Anthropic

**v1.0** · A fictional AI-industry crime-comedy browser game.

**[Play online](https://mws19901118.github.io/GrandTheftAnthropic/)** · Or open `index.html` locally in a modern desktop browser. No installation or build step.

Complete eight Claude Code briefings, survive rival pursuits, solve AI-themed puzzles, defend Anthropic HQ, and reach the IPO. Earn money through courier contracts, buy and upgrade properties, and unlock multiple endings.

**Controls:** WASD / arrows — move or drive · E — interact / enter vehicle · Space — boost · B — properties · G — courier contracts · U — garage · P — save · L — load · Shift+R — restart.

Progress is saved locally in your browser. For architecture and development notes, see [ARCHITECTURE.md](ARCHITECTURE.md).
