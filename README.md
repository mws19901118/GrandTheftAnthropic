# Grand Theft Anthropic

A satirical, English-language, isometric browser game set in AI Vice City.

## Current release

The current playable build is **v1.9**. Its game files (`index.html`, `*.js`, `style.css`, `assets/`) still need to be added to this repository before GitHub Pages can serve the game.

## Local play

Once the files are added at the repository root, open `index.html` in a browser. If browser restrictions affect local assets, run a static local HTTP server.

## GitHub Pages

After adding the game files, open **Settings → Pages**, select **Deploy from a branch**, `main`, `/(root)`. The expected URL is https://mws19901118.github.io/GrandTheftAnthropic/.

## Development

Keep game logic, story, map, and rendering assets decoupled. Preserve the existing campaign, property economy, save system, and BUSTED mechanic. The next priority is correcting NVIDIA Warehouse loading-bay alignment and forklift animation.
